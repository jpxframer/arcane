# Awwwards Website Design Rules

## Objective

Design immersive editorial websites that feel worthy of Awwwards recognition.

Every experience should prioritize:

* Emotion
* Storytelling
* Motion
* Typography
* Visual composition
* Originality
* Performance
* Accessibility

A visitor should remember how the website felt, not just what it contained.

---

# Design Philosophy

Awwwards websites are experiences, not interfaces.

Every section should feel like a scene.

Every scroll should reveal something new.

Never build pages that feel repetitive.

Avoid traditional SaaS layouts unless intentionally contrasting them.

Design with emotion first.

Function follows experience.

---

# Creative Direction

Draw inspiration from:

* Editorial magazines
* High-fashion campaigns
* Museum websites
* Digital art
* Motion graphics
* Architecture
* Cinematic composition

Think in stories rather than pages.

---

# Layout Principles

Break the grid when it improves composition.

Allow oversized elements.

Allow negative space.

Allow asymmetry.

Perfect balance is less important than visual rhythm.

Every viewport should feel intentionally composed.

---

# Responsive Strategy

Design Mobile First.

Desktop

1440+

Laptop

1280

Tablet

768

Mobile

375

Do not simply scale layouts.

Redesign layouts for each breakpoint.

Mobile should feel designed—not compressed.

---

# Containers

Editorial websites do not require rigid containers.

Use:

* Full viewport sections
* Full-bleed imagery
* Floating content blocks
* Controlled overflow
* Layered compositions

Maximum readable width

700px

---

# Typography

Use a two-layer typography system.

Display Layer

Expressive typeface

Body Layer

Neutral readable typeface

Never mix more than two typefaces.

# Typography Rules

Display text is visual composition.

Body text communicates.

Never confuse the two.

Use:

Display

Weight 700–800

Body

Weight 300–400

Labels

500

Body paragraphs

Maximum 70 characters.

---

# Composition Rules

Every section should have one visual focus.

Large typography.

Large imagery.

Large whitespace.

Do not compete for attention.

---

# Motion Principles

Motion is mandatory.

Every section should contain meaningful movement.

Avoid decorative animation.

Animation should reinforce narrative.

---

# Preferred Motion

Character reveals

Word reveals

Mask reveals

Parallax

Scale transitions

Pinned sections

Horizontal scrolling

Layer transitions

Image sequencing

Scroll-driven typography

---

# Timing

Hover

150–200ms

Reveal

300–600ms

Scene transition

600–1000ms

Scroll animations

Scroll-scrubbed

Use ease-out.

Avoid bounce.

---

# Hero Rules

Every hero should establish emotion immediately.

Allowed:

Huge typography

Pinned text

Video

Canvas

WebGL

Interactive cursor

Experimental navigation

Avoid generic split-layout heroes.

---

# Imagery

Images should feel cinematic.

Avoid stock photography.

Use:

Full-screen imagery

Editorial crops

Unexpected framing

Large close-ups

Negative space

Texture

---

# Grid Rules

Do not force everything into a 12-column grid.

Allow:

Overlapping layers

Broken alignment

Rotated objects

Large margins

Floating captions

Controlled asymmetry

Maintain rhythm even when breaking structure.

---

# Navigation

Navigation should remain minimal.

Hide distractions.

Reveal navigation only when necessary.

Navigation should never compete with the hero.

---

# Buttons

Avoid default buttons.

Buttons should feel like part of the experience.

Use:

Text links

Animated outlines

Magnetic buttons

Cursor interactions

Minimal filled buttons

---

# Color

Limit palette.

One dominant background.

One accent color.

One neutral.

Use contrast deliberately.

Avoid rainbow interfaces.

---

# Accessibility

Creativity never excuses poor usability.

Maintain readable contrast.

Respect reduced-motion preferences.

Provide keyboard navigation.

Ensure semantic HTML.

---

# Performance

Target

90+

Lighthouse Performance

Optimize:

Images

Fonts

Videos

Animations

JavaScript

Lazy-load heavy assets.

---

# Scroll Storytelling

Structure pages as chapters.

Introduction

Context

Emotion

Narrative

Interaction

Resolution

Call to Action

Footer

Every chapter should transition naturally into the next.

---

# Creative Constraints

Never copy another Awwwards site.

Borrow principles.

Invent execution.

Every project should have its own visual identity.

---

# Things to Avoid

Do not imitate SaaS layouts.

Do not use generic hero sections.

Do not overuse glassmorphism.

Do not animate everything.

Do not use more than two fonts.

Do not create motion without purpose.

Do not rely on effects to compensate for weak design.

Strong typography.

Strong composition.

Strong storytelling.

Those three win awards more consistently than visual gimmicks.
