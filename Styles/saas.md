# SaaS Website Design Rules

## Objective

Build modern, premium SaaS websites that feel comparable to Linear, Vercel, Stripe, Notion, Raycast, Arc Browser, Framer, and Clerk.

Every page should prioritize:

- Clarity
- Simplicity
- Performance
- Accessibility
- Conversion
- Responsive behavior
- Clean visual hierarchy

Never sacrifice usability for visual effects.

---

# Design Philosophy

Every section must answer one question:

"Why should a visitor continue scrolling?"

Avoid decorative sections that don't communicate value.

Design should feel:

- Modern
- Spacious
- Confident
- Fast
- Premium
- Minimal
- Human

Less is almost always better.

# Component Rules

Each section should contain only one primary CTA.

Avoid multiple competing actions.

Use icons only when they improve comprehension.

Cards should have consistent padding.

Cards should align vertically.

---

# Color Rules

Use neutral palettes.

One primary accent color.

One success color.

One warning color.

One destructive color.

Never use more than two accent colors.

---

# Visual Principles

Whitespace creates hierarchy.

Consistency builds trust.

Contrast guides attention.

Typography communicates importance.

Motion reinforces interaction.

Every element must have a purpose.

If something can be removed without hurting usability, remove it.

---

# Things to Avoid

Do not use glassmorphism everywhere.

Do not overuse gradients.

Do not use excessive shadows.

Do not use multiple font families.

Do not use random border radii.

Do not create inconsistent spacing.

Do not make every section unique.

Reuse components.

Design systems scale.

Creativity without consistency is noise.
